# retro

> 复盘记录：不复盘的经验，只是经历。

## 简介

这里存放阶段性的复盘——事情做完之后，把做对的和做错的写下来。目的不是写总结交差，而是让下一次不再犯同样的错。

## 目录结构

| 目录 / 文件 | 说明 |
| --- | --- |
| `weekly/` | 周度复盘，文件名如 `2026-w42.md` |
| `project/` | 项目结项后的专项复盘 |
| `patterns.md` | 跨多次复盘反复出现的问题，单独提炼 |
| `templates/retro-template.md` | 复盘模板 |

## 复盘格式

四段写完，别写成流水账：

```markdown
# [对象] 复盘 YYYY-MM-DD

- 预期：当初想达成什么
- 实际：最后是什么结果
- 差异：差在哪里，为什么
- 行动：下次具体改哪一步（写动作，不写"下次注意"）
```

## 写作原则

- 对事不对人，包括对自己——写"排期没留缓冲"，不写"我太拖了"
- 差异分析必须挖到根因，停在现象层面的复盘没有用
- 行动项要具体到能直接执行，"下次注意"不算行动
- 同样的差距出现第二次，就要升级成机制问题，写进 `patterns.md`
